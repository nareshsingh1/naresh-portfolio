# Naresh Singh — Developer Portfolio

A responsive, static developer portfolio built with vanilla HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in a browser. No build step or dependencies are required.

## Before publishing
1. Review your displayed email and phone number in `index.html` before publishing.
2. Review the experience and project descriptions for accuracy and remove anything you cannot publicly share.
3. Add your LinkedIn and GitHub links if you want them displayed.
4. If you want a working contact form instead of an email link, connect a form backend or a form service. The current button opens the visitor's email application.

## Deploy
You can host these static files on GitHub Pages, Cloudflare Pages, or any static web host. Upload `index.html`, `style.css`, and `script.js` together.
